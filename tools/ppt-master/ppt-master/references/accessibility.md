# 无障碍设计检查清单（可选参考）

确保 PPT 设计更具包容性，适合更多观众。这些原则来源于 WCAG 无障碍标准。

---

## 核心原则

1. **可感知** - 信息必须以用户可以感知的方式呈现
2. **可操作** - 用户界面组件必须可操作
3. **可理解** - 信息和界面操作必须可理解
4. **健壮性** - 内容必须足够健壮，能被各种辅助技术解析

---

## PPT 设计无障碍检查

### 🔴 P0 - 必须注意

#### 颜色对比度

- [ ] **正文文本**：深色背景上的浅色文字，对比度 ≥ 4.5:1
- [ ] **大文本 (18px+)**：对比度 ≥ 3:1
- [ ] **UI 组件**：按钮、导航元素对比度 ≥ 3:1
- [ ] **不能仅靠颜色传达信息** - 必须有文字/图标辅助

#### 图像替代文本

- [ ] **所有图片有 alt 描述** - 说明图片内容（不在PPT中显示，但供辅助技术使用）
- [ ] **装饰性图片** - 可以省略描述
- [ ] **复杂图像** - 图表、流程图等需要有文字说明

### 🟡 P1 - 强烈建议

#### 字体和排版

- [ ] **可缩放** - 字体不要过小（正文≥18pt）
- [ ] **行高足够** - 行高 ≥ 1.5倍
- [ ] **避免过密文字** - 每页不要超过6-7行

#### 语义结构

- [ ] **标题层级正确** - 不要跳级（如：从标题1直接到标题3）
- [ ] **列表使用项目符号** - 不要用破折号模拟
- [ ] **章节有标题** - 每章节开始应有明确标题

### 🟢 P2 - 最佳实践

#### 动画和动效

- [ ] **避免快速闪烁** - 不要有3次/秒以上的闪烁
- [ ] **动画时长合理** - 每页动画≤3秒
- [ ] **考虑"减少动画"偏好** - 在设计时就要考虑

#### 链接和导航

- [ ] **链接文本有意义** - 避免"点击这里"、"更多"
- [ ] **外部链接标记** - 说明会跳转到外部

---

## 快速检查清单

```
□ 每页文字对比度是否足够？
□ 颜色不是唯一的信息载体？
□ 图表数据有文字描述？
□ 字体大小是否可读？
□ 标题层级是否正确？
□ 是否有适当的留白？
□ 避免快速闪烁的动画？
□ 内容结构清晰？
```

---

## 场景建议

| 场景 | 无障碍重点 |
|------|-----------|
| 企业培训 | 确保色彩对比度，考虑色盲观众 |
| 学术汇报 | 字体大小足够，图表有文字说明 |
| 产品发布 | 避免过度依赖颜色，使用图标辅助 |
| 国际会议 | 考虑多语言文字长度，预留空间 |
