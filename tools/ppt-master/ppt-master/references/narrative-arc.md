# 叙事弧模板（Narrative Arc）

内容结构化的方法论，适用于所有 PPT 场景。这套模板来自真实演讲实践的沉淀，帮助你组织内容、打造有说服力的演示。

---

## 核心叙事弧

```
钩子(Hook)       → 1 页   : 抛一个反差 / 问题 / 硬数据让人停下来
定调(Context)    → 1-2 页 : 说明背景 / 你是谁 / 为什么讲这个
主体(Core)       → 3-5 页 : 核心内容,用版式穿插
转折(Shift)      → 1 页   : 打破预期 / 提出新观点
收束(Takeaway)   → 1-2 页 : 金句 / 悬念问题 / 行动建议
```

---

## 叙事弧详解

### 1. 钩子（Hook）— 第1页

**目的**：让人停下来，3秒内抓住注意力

**类型**：
| 类型 | 示例 | 适合场景 |
|------|------|----------|
| 反差型 | "我不是程序员，但我做出了10万行代码的产品" | 个人品牌、技术分享 |
| 数据型 | "过去30天，我们营收增长了200%" | 商业汇报、工作汇报 |
| 问题型 | "为什么你的PPT总是没人看？" | 培训、分享 |
| 金句型 | "未来已来，只是分布不均" | 产品发布、TED |

**要点**：
- 一页只说一件事
- 标题即结论
- 不要有过渡语

### 2. 定调（Context）— 第2-3页

**目的**：建立信任，说明为什么你来讲这个

**内容**：
| 内容 | 说明 | 可选 |
|------|------|------|
| 背景 | 我在什么情况下做这件事 | ✅ |
| 身份 | 我是谁，为什么我能讲 | ✅ |
| 前提 | 假设观众需要知道什么 | ✅ |
| 目标 | 今天结束后你能带走什么 | ✅ |

**禁忌**：
- ❌ "大家好，我是XXX，很荣幸今天来分享..."
- ❌ 过长的自我介绍
- ❌ 放公司介绍（除非你就是公司品牌本身）

### 3. 主体（Core）— 第4-8页

**目的**：核心内容的展开

**结构建议**：
| 结构 | 适合 | 页数 |
|------|------|------|
| 问题-方案 | 解决方案类 | 3-4页 |
| 过去-现在-未来 | 成长/变化类 | 3-4页 |
| 是什么-为什么-怎么办 | 方法论类 | 4-5页 |
| 挑战-行动-结果 | 项目汇报类 | 3-4页 |

**节奏控制**：
- 每3-4页插入一个"大字报"页（数字/金句）
- 不要连续3页以上相同的版式
- 保持"密集页"和"大字报页"交替

### 4. 转折（Shift）— 第9页左右

**目的**：打破预期，提出新观点

**类型**：
| 类型 | 示例 |
|------|------|
| 意外发现 | "但我们发现，真正的问题不在这里..." |
| 反常识结论 | "越努力越失败？一个新的认知框架" |
| 新视角 | "从另一个角度看这个问题..." |
| 悬念 | "这就是为什么..." |

**要点**：
- 不要太长，1页足够
- 制造"原来如此"的顿悟感
- 可以是主体最后一个"章节页"

### 5. 收束（Takeaway）— 最后1-2页

**目的**：让人记住一件事，带走行动

**内容**：
| 类型 | 示例 |
|------|------|
| 金句 | "一句话总结你的核心观点" |
| 行动建议 | "现在你可以做的3件事" |
| 回顾 | "今天我们讲了..." |
| CTA | "扫码领取资料/加入社群" |

**禁忌**：
- ❌ "以上就是我的分享，谢谢大家"
- ❌ 联系方式放太多页
- ❌ "有问题欢迎随时联系"（没有具体行动指引）

## 页数规划参考

| 时长 | 总页数 | 分配 |
|------|--------|------|
| 5分钟 | 8-10页 | Hook(1) + Context(1) + Core(5) + Shift(1) + Takeaway(1) |
| 15分钟 | 15-20页 | Hook(1) + Context(2) + Core(10) + Shift(2) + Takeaway(2) |
| 30分钟 | 25-30页 | Hook(1) + Context(2) + Core(18) + Shift(3) + Takeaway(3) |
| 60分钟 | 40页+ | 按需扩展Core部分，每15分钟一个章节 |

---

## 与 Q1-Q9 的整合

叙事弧是**内容结构化**的宏观框架，Q1-Q9 是**单页设计**的微观检查。

**使用流程**：
1. 用叙事弧规划整体结构（几页、每页什么角色）
2. 用 Q1-Q9 检查每一页（记忆点、字体、对比）
3. 用 CRAP 四原则微调视觉（对齐、接近、重复、对比）

**示例整合**：
```
页面 1（Hook）：
  - 叙事弧角色：钩子，吸引注意力
  - Q4 记忆点：核心数据或金句
  - 版式：全图型或大字报

页面 4-8（Core）：
  - 叙事弧角色：主体内容
  - Q1-Q3：明确观众、行动、需求层级
  - Q5：二等（说明白）或一等（打动人）
  - 穿插"大字报"页调节节奏
```

---

## 叙事弧检查清单

```
□ 第1页：是否在3秒内抓住了注意力？
□ 第1页：是否说清了"今天要讲什么"？
□ 第2-3页：是否建立了足够的信任/背景？
□ Core部分：是否有明确的逻辑线？
□ Core部分：是否每3-4页有一个"大字报"？
□ Shift页：是否制造了"顿悟"感？
□ 最后1页：是否能用一句话总结今天？
□ 最后1页：是否有明确的行动指引？
□ 整体：是否有"废话"可以删掉？
```

## 叙事弧示例

### 示例1：个人品牌分享（15分钟）

| 页 | 叙事弧 | 版式 | 内容 |
|----|--------|------|------|
| 1 | Hook | 大字报 | "我是程序员，但我花3年做出了百万用户的产品" |
| 2 | Context | 左文右图 | 我的背景：从代码到产品 |
| 3 | Context | 时间轴 | 3年关键节点 |
| 4 | Core | 三栏卡片 | 第一个发现：用户不是上帝 |
| 5 | Core | 左文右图 | 具体案例和数据 |
| 6 | Core | 大字报 | 数字：用户留存提升了200% |
| 7 | Core | Pipeline | 第二个发现：增长黑客是幻觉 |
| 8 | Core | 左右对比 | 幻觉 vs 现实 |
| 9 | Shift | 大引用 | "真正有效的，是笨办法" |
| 10 | Core | 三栏卡片 | 笨办法1：用户访谈 |
| 11 | Core | Pipeline | 笨办法2：快速迭代 |
| 12 | Takeaway | 收尾 | 一句话 + 3个行动 |

### 示例2：工作汇报（10分钟）

| 页 | 叙事弧 | 版式 | 内容 |
|----|--------|------|------|
| 1 | Hook | 大字报 | "Q2营收超额完成120%" |
| 2 | Context | 概述 | 项目背景和目标 |
| 3 | Core | 时间轴 | 关键里程碑 |
| 4 | Core | 图表 | 数据增长曲线 |
| 5 | Core | 卡片 | 3个成功因素 |
| 6 | Shift | 问题 | "但我们也发现了3个问题" |
| 7 | Core | 对比 | 问题 vs 解决方案 |
| 8 | Takeaway | 收尾 | Q3计划 + 需要支持 |
