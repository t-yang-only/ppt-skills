## 使用建议

| 场景 | 推荐方案 |
|------|----------|
| AI/技术产品发布 | 深空蓝、赛博脉冲 |
| 企业年度汇报 | 企业深蓝、商务翡翠 |
| 营销/活动策划 | 活力橙、艺术紫 |
| 学术/论文答辩 | 学术蓝 |
| 管理咨询报告 | 咨询灰 |
| 培训/教学课件 | 参考 color-system.md 的教育配色 |

---

## 配色选择决策树

```
用户场景
    ↓
[内容类型]
    ├── AI/科技 → 深空蓝或赛博脉冲
    ├── 企业/B2B → 企业深蓝或商务翡翠
    ├── 营销/活动 → 活力橙
    ├── 设计/艺术 → 艺术紫
    ├── 学术/论文 → 学术蓝
    ├── 咨询/战略 → 咨询灰
    └── 其他 → 参考 color-system.md
```

---

## 重要提醒

> ⚠️ **配色只是起点，不是终点**
>
> - 这些配色方案提供视觉参考
> - 根据具体内容和品牌调整
> - 保持对比度足够（参考 accessibility.md）
> - 一页不要超过3种主色
