# taskpkg-irregular-shapes-and-matting: 异形图片蒙版、不规则抠图与透明素材装配规范

> 核心定位：打破传统 PPT 方方正正的机械排版，提供高审美不规则形状裁切（有机流体 Blob、苹果超椭圆、斜切卡片等）、局部高精度套索抠图与去白边精修，实现素材元素级 1:1 灵活装配。

---

## 1. 为什么需要不规则形状与高精度抠图？

传统 AI 生成 PPT 的常见短板：
1. **死板方框堆砌**：图片只能以矩形卡片插入，版面呆板单调，缺乏杂志大片的高级呼吸感与视觉冲击。
2. **带底噪与脏背景**：很多素材带有复杂杂色背景或生硬白边，直接插入深色或浅灰卡片上会出现严重违和感。
3. **无法局部截取精修**：一张大图往往只有局部核心主体（如机械臂关节、芯片核心、某个人物）需要作为幻灯片焦点，传统工具无法完成“局部截取 -> 智能抠图 -> 异形裁切 -> 放置”的闭环。

## 2. 9 种不规则高级形状蒙版 (Shape Image Masking)

脚本工具：`scripts/shape_image_mask.py`

| 形状 ID | 形状名称 | 视觉特征与审美价值 | 推荐应用场景 |
|---|---|---|---|
| `blob` | 有机流体形 (Organic Blob) | 多阶贝塞尔平滑有机水滴/液态流动形，打破矩形呆板束缚 | 封面核心视觉主体、创意科技、大片级留白配图 |
| `squircle` | 苹果超椭圆 (Superellipse) | 平滑连续曲率 $(x/a)^4 + (y/b)^4 = 1$，超越普通圆角的高级感 | 现代高端产品展示、UI/SaaS 卡片图、科技硬件 |
| `hexagon` | 蜂巢正六边形 | 锐利严谨的几何秩序，支持多六边形矩阵交错平铺 | 工业互联网、数据枢纽、分布式节点、流程矩阵 |
| `octagon` | 现代八边形 | 科技切角设计，消除尖锐感同时保留硬核气质 | 军工科研、硬核制造、安全防御体系 |
| `slanted_card` | 杂志斜切卡片 | 对角倾斜裁切，形成动感倾斜视线与强动线张力 | 商业快报、运动时尚、前沿战略、对比展示 |
| `diamond` | 菱形旋转正方形 | 独特的几何对称视觉焦点 | 核心里程碑、金牌认证、核心人物特写 |
| `teardrop` | 水滴泪珠形 | 弧形与尖角结合的有机形态 | 生物医药、生态环保、新能源液体材料 |
| `chevron` | 导向箭头形 | 强方向感与阶段推进感 | 流程推进、战略演进路线、重大跨越阶段 |
| `polygon` | 自由多边形顶点 | 传入任意归一化或像素顶点坐标进行不规则裁切 | 任意非标多边形设计稿的 1:1 像素级复刻 |

## 3. 局部截取、智能抠图与去白边精修 (Matting & Defringing)

脚本工具：`scripts/matting_cutout.py`

### 核心处理链路
1. **局部截取 (ROI Crop)**：
   - 支持 `--crop "0.15,0.1,0.85,0.9"` 归一化比例截取，或 `--crop "x,y,w,h"` 像素级精准框选核心主体。
2. **不规则多边形套索 (Polygon Lasso)**：
   - 支持 `--polygon "x1,y1;x2,y2;x3,y3..."`，沿着复杂主体轮廓绘制任意多边形，生成带亚像素级平滑抗锯齿的蒙版。
3. **本地离线智能背景剔除 (Local GrabCut Matting)**：
   - 内置基于 OpenCV 的 GrabCut 迭代算法，无需联网、零依赖外部付费 API，纯本地瞬间剥离纯色或复杂单色背景。
4. **去白边与边缘光晕精修 (Defringing & Alpha Erosion)**：
   - 针对抠图后在暗色背景下容易出现的白边锯齿与边缘泛白现象，自动执行 1~2px 形态学收缩与高斯边缘羽化，保证与任何底色卡片完美融合。

---

## 4. 原生 PPTX 一键植入

两个脚本均支持直接将处理好的透明/异形图片注入目标 PPTX：
```bash
# 裁切为有机流体并注入幻灯片第 1 页
python scripts/shape_image_mask.py input.png --pptx deck.pptx --slide 1 --shape blob --left 1.5 --top 1.5 --width 4.0

# 抠出透明主体并放置在第 2 页指定卡片内
python scripts/matting_cutout.py input.png --auto-bg --pptx deck.pptx --slide 2 --left 4.5 --top 2.0 --width 3.5
```
