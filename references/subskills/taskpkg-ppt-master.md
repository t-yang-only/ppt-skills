# taskpkg-ppt-master: 存量 PPTX 全量美化与母版重构规范

> 对应顶流开源规范 `hugohe3/ppt-master`（⭐38k）。
> 核心定位：专门接收已有 `.pptx` 文件做全量美化、网格重构、版式重排、卡片化与母版对齐；**不是从零生成 PPT，严禁纯图片整页贴图**。

---

## 1. 核心定位与适用场景

- **适用场景**：答辩 PPT、项目汇报、竞赛 PPT（挑战杯、创青春、互联网+、西门子杯、国创等）。
- **处理对象**：已具备完整文案与基本结构的已有 `.pptx`。
- **输出标准**：**100% 原生可编辑 PPTX 对象**（文字、形状、原生表格、原生图表），文本可直接选中编辑，形状可缩放无失真，严禁导出为图片贴回。

---

## 3. 核心美化重构动作 (The 6 Transformations)

1. **网格系统重塑 (Grid Re-architecture)**：
   - 将杂乱漂移的元素吸附至 12 列网格基准线上；
   - 统一外边距（左右 ≥ 5%，上下 ≥ 6%），消除呼吸局促感。
2. **卡片化容器规整 (Cardification)**：
   - 将相关联的文本和图表打包装入规范卡片容器中；
   - 卡片背景设为 30% 辅助基色（如浅灰 #F5F5F7），配合 1px 细微边界线，放弃沉重描边与刺眼投影。
3. **字体族系统归一 (Typography Harmonization)**：
   - 全篇严格锁定 1 套标题字体 + 1 套正文字体；
   - 标题：微软雅黑 / Arial / 思源黑体；
   - 正文：微软雅黑 / Inter / 思源黑体；
   - 坚决杜绝一页 PPT 出现 4 种以上不同字体的混乱局面。
4. **字号阶梯规范 (Typographic Scale)**：
   - 页面主标题：28 ~ 36 pt (Bold)
   - 模块/卡片小标题：18 ~ 22 pt (Bold)
   - 正文一级要点：13 ~ 15 pt (Regular)
   - 辅助图注/来源：11 ~ 12 pt (Muted)
   - **硬性红线**：禁止正文低于 11.5 pt！
5. **消除文字溢出 (Zero-Overflow Defense)**：
   - 所有文本框强制激活 `word_wrap = True`；
   - 优化文本框内边距（收紧默认 0.1 英寸边距至 4pt 上下、6pt 左右），释放 15%~25% 有效可视区域。
6. **图表与原生对象重建 (Native Rebuilding)**：
   - 将原稿中由外部粘贴的马赛克截图图表，用 python-pptx 原生 Chart 或格式化 Table 重新绘制。

## 4. 自动化调用工具

使用配套工具执行全量美化：
```bash
# 执行瑞士极简风格美化
python scripts/polish_pptx.py input.pptx -o output_polished.pptx --theme swiss

# 执行国赛答辩风格美化
python scripts/polish_pptx.py input.pptx -o output_competition.pptx --theme competition
```
